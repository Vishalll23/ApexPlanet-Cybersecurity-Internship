
# CIA Triad in Cybersecurity

## Introduction
The CIA Triad is a fundamental security model used to protect information and computer systems. CIA stands for Confidentiality, Integrity, and Availability.

It helps organizations maintain the security and reliability of their data.

## 1. Confidentiality
Confidentiality ensures that information is accessible only to authorized users.

**Examples:**
- Using passwords to protect user accounts.
- Encrypting sensitive files.
- Implementing access control.

**Real-world scenario:**
A banking application allows customers to view their own account details but prevents unauthorized users from accessing them.

## 2. Integrity
Integrity ensures that information remains accurate, complete, and unchanged unless modified by an authorized person.

**Examples:**
- Using file hashes to detect unauthorized changes.
- Implementing database access controls.
- Maintaining audit logs.

**Real-world scenario:**
A student marksheet must not be modified by an unauthorized person.

## 3. Availability
Availability ensures that systems, services, and information remain accessible to authorized users whenever required.

**Examples:**
- Regular data backups.
- Using redundant servers.
- Protecting systems against DDoS attacks.

**Real-world scenario:**
An online banking website should remain accessible to customers even during high traffic.

## Importance of the CIA Triad

| Principle | Main Goal | Example |
|---|---|---|
| Confidentiality | Protect data privacy | Passwords |
| Integrity | Maintain data accuracy | File hashing |
| Availability | Ensure accessibility | Backups |

## Conclusion
The CIA Triad provides the foundation for information security. All three principles work together to protect data from unauthorized access, modification, and service disruption.
